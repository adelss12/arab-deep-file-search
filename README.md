# المستكشف العميق للملفات والصور 🔎

واجهة عربية للبحث داخل محتوى المستندات والجداول والعروض التقديمية والملفات النصية، مع استخراج النصوص من الصور باستخدام التعرف البصري على الحروف **OCR**.

المشروع تطبيق ويب ثابت في ملف `index.html` واحد، يعمل داخل المتصفح دون تثبيت برنامج مكتبي أو إعداد قاعدة بيانات.

## المميزات

- واجهة عربية باتجاه RTL، مع مظهر ليلي ونهاري.
- إضافة ملفات متعددة بالسحب والإفلات أو اختيارها من الجهاز، واستيراد مجلد بحسب دعم المتصفح.
- فهرسة المحتوى مع إظهار موقع النتيجة: خلية وورقة، فقرة وجدول، صفحة، شريحة أو سطر.
- البحث في قيم خلايا Excel ومعادلاتها وتعليقاتها.
- تحديد الملفات المشمولة بالبحث وتصفيتها بالاسم أو النوع.
- تمييز الكلمات المطابقة ومعاينة النص المستخرج والتنقل بين التطابقات.
- إدراج نص أو جدول منسوخ مباشرة للبحث فيه.
- نسخ النتائج وتصدير تقرير بصيغة **CSV** أو **Excel (.xlsx)**.
- بيانات تجريبية مدمجة لتجربة الواجهة دون اختيار ملفات شخصية.

## أنواع الملفات

| النوع | الصيغ الأساسية | المحتوى الذي تتم قراءته |
| --- | --- | --- |
| Word | `.docx` | الفقرات والجداول والرؤوس والتذييلات والحواشي والتعليقات |
| الجداول | `.xlsx`، `.xls`، `.csv`، `.ods` | الخلايا والمعادلات والتعليقات، مع اسم الورقة وعنوان الخلية |
| PDF | `.pdf` | طبقة النص الموجودة داخل الصفحات |
| PowerPoint | `.pptx` | النصوص الموجودة في الشرائح |
| الصور | `.png`، `.jpg`، `.jpeg`، `.webp`، `.bmp`، `.gif` | استخراج النصوص العربية والإنجليزية عبر OCR، بحسب دعم المتصفح |
| النصوص والأكواد | مثل `.txt`، `.md`، `.json`، `.xml`، `.html`، `.log`، `.sql`، `.py`، `.js`، `.ts` | المحتوى النصي سطرًا بسطر |

> ظهور امتداد ضمن تصنيف الواجهة لا يعني وجود قارئ كامل له. دعم Word وPowerPoint يعتمد أساسًا على DOCX وPPTX؛ يُفضّل تحويل DOC وPPT وODT وRTF وODP إلى الصيغ الأساسية قبل الاستيراد.

## التشغيل

### على جهازك

1. نزّل المشروع من **Code → Download ZIP** ثم فك الضغط.
2. افتح ملف `index.html` في متصفح حديث.
3. إذا تعذّر تحميل محرك OCR أو إحدى المكتبات عند فتح الملف مباشرة، شغّله باستخدام إضافة **Live Server** في VS Code.

لا يحتاج المشروع إلى `npm install` أو Python أو تثبيت Tesseract على Windows؛ يستخدم نسخة JavaScript داخل المتصفح.

**تحتاج النسخة الحالية إلى اتصال بالإنترنت** لتحميل المكتبات والخطوط وموارد محرك OCR. ليست حزمة مستقلة مضمونة للعمل دون إنترنت.

### عبر GitHub Pages

يمكن استضافة المشروع بوصفه موقعًا ثابتًا:

1. افتح **Settings → Pages** في المستودع.
2. اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
4. افتح الرابط الذي يظهر في صفحة Pages بعد اكتمال النشر.

## طريقة الاستخدام

1. جرّب زر **ملفات تجريبية جاهزة** للتعرف على الواجهة، أو امسح القائمة ثم أضف ملفاتك.
2. انتظر انتهاء الفهرسة، وتأكد من تحديد الملفات المطلوبة في القائمة الجانبية.
3. اكتب عبارة البحث واختر نمط البحث المناسب.
4. اضبط خيارات العربية والأرقام والمطابقة من الخيارات المتقدمة عند الحاجة.
5. افتح معاينة النتيجة للاطلاع على النص المستخرج وموقع التطابق.
6. انسخ النتائج أو صدّرها إلى CSV أو Excel.

مسح ملف من القائمة يزيله من جلسة التطبيق؛ لا يحذف الملف الأصلي من جهازك.

## أنماط البحث

| النمط | الاستخدام |
| --- | --- |
| شامل ذكي | يبحث عن جميع كلمات الاستعلام داخل المقطع نفسه |
| عبارة دقيقة | يبحث عن العبارة متتابعة، مع مراعاة خيارات التطبيع المفعّلة |
| كل الكلمات (AND) | يشترط وجود كل الكلمات داخل المقطع نفسه |
| أي كلمة (OR) | يعرض المقطع عند وجود أي كلمة من الاستعلام |
| نطاق رقمي | يبحث عن أرقام بين حد أدنى وحد أعلى |
| تعبير نمطي (Regex) | يبحث بنمط مخصص، مثل `INV-\\d+` |

تتوفر اختصارات للبحث عن الأرقام والمبالغ والنسب والهواتف والآيبان وأرقام من 10 خانات والتواريخ والبريد والروابط والرموز ومعادلات Excel. هذه الاختصارات تكشف أنماطًا نصية، ولا تتحقق من صحة الهوية أو الحساب البنكي.

### خيارات العربية والمطابقة

يمكن تجاهل التشكيل، وتوحيد صور الهمزة وبعض الحروف العربية، وتوحيد الأرقام العربية والإنجليزية، وتفعيل مطابقة الكلمة الكاملة أو حساسية حالة الأحرف الإنجليزية. كما يمكن تضمين معادلات Excel وتغيير طول السياق المعروض.

المطابقة تتم على مستوى **المقطع المفهرس**؛ فمثلًا قد لا يظهر ملف عند استخدام AND إذا كانت الكلمات موزعة على خلايا أو فقرات مختلفة.

## استوديو قراءة الصور OCR

يتيح الاستوديو:

- إدراج صورة من الجهاز أو لصقها من الحافظة عبر `Ctrl+V` بحسب دعم المتصفح.
- اختيار العربية أو الإنجليزية أو اللغتين معًا.
- تدوير الصورة وتطبيق التدرج الرمادي أو زيادة التباين أو التحويل إلى أبيض وأسود.
- عرض النص المستخرج ونسخه أو تنزيله كملف نصي.
- إضافة النص المستخرج إلى فهرس البحث.

> **ملاحظة على النسخة الحالية:** عند فشل OCR أو عدم استخراج نص في الاستوديو، ينتقل الكود إلى عرض نص فاتورة تجريبية، وقد تظهر معه رسالة نجاح ونسبة ثقة. إذا ظهرت فاتورة لا تخص صورتك فلا تعتمد عليها بوصفها قراءة فعلية. كذلك بعض نسب الثقة لها قيم افتراضية وليست قياسًا مضمونًا من المحرك.

## الخصوصية وحفظ البيانات

- قراءة الملفات والبحث وعمليات OCR تنفذ داخل المتصفح؛ لا يتضمن كود التطبيق خادمًا لرفع الملفات أو حسابات مستخدمين.
- تُحمّل مكتبات وخطوط وموارد OCR من جهات خارجية، ولذلك توجد اتصالات شبكة عند تشغيل التطبيق.
- الملفات والفهرس والنتائج محفوظة في ذاكرة جلسة الصفحة؛ يلزم إعادة الاستيراد عند تحديث الصفحة أو إغلاقها.
- يُحفظ اختيار المظهر فقط في `localStorage`.
- تصدير النتائج يحفظ تقريرًا، ولا ينشئ نسخة احتياطية من الملفات الأصلية.

## حدود النسخة الحالية

<ul dir="rtl" align="right">
<li dir="rtl" align="right"><strong>PDF الممسوح ضوئيًا:</strong> قارئ PDF يستخرج طبقة النص فقط؛ لا يطبّق OCR تلقائيًا على صور الصفحات. يمكن تحويل الصفحات إلى صور واستخدام استوديو OCR.</li>
<li dir="rtl" align="right"><strong>المعاينة:</strong> تعرض النصوص المفهرسة، وليست عرضًا مطابقًا لتنسيق المستند الأصلي.</li>
<li dir="rtl" align="right"><strong>مسار الملف:</strong> يبني التطبيق المسار المعروض من حقل المجلد الجذري والمسار النسبي أو تصنيف افتراضي. لا يستطيع المتصفح اكتشاف المسار الكامل الحقيقي لكل ملف؛ راجع المسار قبل الاعتماد عليه.</li>
<li dir="rtl" align="right"><strong>التأشير على الملف:</strong> إجراء المسار يعرض معلوماته داخل التطبيق وينسخها؛ لا يفتح مستكشف ملفات Windows ويحدد الملف تلقائيًا.</li>
<li dir="rtl" align="right"><strong>تكرار الأسماء:</strong> استيراد ملف بالاسم نفسه يستبدل مدخله السابق في الفهرس، حتى لو كان من مجلد مختلف.</li>
<li dir="rtl" align="right"><strong>الأداء:</strong> الملفات الكبيرة أو الصور الكثيرة قد تستهلك وقتًا وذاكرة؛ ابدأ بدفعات صغيرة.</li>
<li dir="rtl" align="right"><strong>دقة OCR:</strong> تتأثر بجودة الصورة واتجاهها والخط والإضاءة؛ راجع النصوص والأرقام المستخرجة.</li>
<li dir="rtl" align="right"><strong>التوافق:</strong> اختيار المجلدات ولصق الصور وقراءة بعض صيغ الصور يتوقف على المتصفح والجهاز.</li>
</ul>
